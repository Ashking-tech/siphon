Linux media converter

Convert in place.
No second copy.

Siphon converts video, audio, images and PDFs. For video, it works in one verified segment at a time by default, so it never needs a second full copy.

Build from source → See formats

Peak extra space for a 60 GB film: about 340 MB.

01 / The difference

A converter should not need room for the file and its replacement.

Every ordinary converter writes a complete second file. Siphon's video engine works backwards from the end of the MKV: copy one keyframe-aligned segment into the MP4, verify it, then release those source bytes. Peak extra space is one segment, not one film.

02 / Get Siphon

Build from source.

You need Go, ffmpeg/ffprobe ≥ 5.0, and lame ≥ 3.100.

CLI

Build and installshell
git clone https://github.com/Ashking-tech/siphon.git
cd siphon
make build
sudo install -Dm755 bin/siphon /usr/local/bin/siphon
siphon doctor

No release binaries yet. Distribution packages are planned. Watch the releases page for the first tagged build.

Dolphin / KDE

Optional ServiceMenu for Plasma 5 and 6.

Install ServiceMenushell
make install-kde

Optional: WebP, Poppler and kdialog for those formats and the menu.

03 / How it works

One verified segment at a time.

01

Inspect

Checks the pair, free space and crash cost. It changes nothing.

02

Convert

Muxes one keyframe-aligned segment into the output, verifies it, then releases those source bytes.

03

Finish

Verifies the result, renames it into place, and removes the source. If interrupted, siphon recover resumes.

Video is remuxed, not transcoded. Audio, images and PDFs use safe temp-file swaps.

04 / Formats

What it converts.

Run siphon inspect to confirm a pair and see the exact space requirement.

Video

MKV→MP4 MP4→MKVnew MOV→MKVnew MKV→MOVnew WebM↔MP4new GIF↔MP4new

MKV → MP4 defaults to relocate. --mode safe writes classic MP4 at 2× space.

Audio

WAV→MP3 VIDEO→MP3new

--mode reclaim is opt-in and uses about 1× space.

Images

PNG↔JPG PNG↔WebP JPG↔WebP

Safe swaps. Alpha needs --bg when the target has no alpha.

Documents

PDF→PNG/JPGnew PNG/JPG→PDFnew

One page per file. Safe-only.

Pairs marked new are in progress for v0.2 and safe-only.

05 / Limits

What it won't do.

Siphon refuses rather than guess. These limits matter before you run it.

  • Linux only. CLI and Dolphin ServiceMenu. No first-class GUI yet.
  • Video is remux-only. One video and one optional audio track. Fragmented MP4 by default.
  • Relocate needs sparse files. ext4, btrfs and XFS work. FAT32, exFAT and NTFS-3G are refused.
  • Audio reclaim is opt-in. A crash can leave a ≤ 26 ms splice. The default safe mode leaves the source untouched until verification.

06 / Questions

A few honest answers.

Is it safe?

Yes. Safe modes keep the source byte-identical until the output is verified and renamed. Video relocate verifies each segment before truncating it. siphon recover resumes after a crash.

How much free space does it need?

Video needs one segment, typically 30–600 MB. Safe-only pairs need room for the source and the output. siphon inspect prints the exact figure.

Does it overwrite my original?

The source is consumed on success. Safe modes leave it untouched until verification. If you need to keep it, copy it first when you have room.

Does it work outside KDE?

Yes. The command line tool works on any Linux desktop or server. The Dolphin ServiceMenu is optional.
